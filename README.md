## Project Title: Custom Theme Cross-Platform GUI Calculator## Project Overview
This project is a lightweight, responsive desktop calculator built in Python using the native Tkinter graphical user interface framework. Designed with a custom aesthetic, it features a sleek Matrix-inspired dark mode consisting of a black-green base, neon-green digital display text, forest-green operations, and deep slate-blue numeric keys.
Unlike standard Tkinter applications that suffer from platform-restricted styling, this application overrides operating system themes (such as macOS and Windows styling defaults) by utilizing fully customized, event-bound interactive components to guarantee identical color rendering and crisp hover behaviors across all environments.
## Key Features

* Cross-Platform Color Consistency: Utilizes customized interactive labels to force custom background and text color rendering, completely bypassing restrictive native OS window skins.
* Interactive UI/UX Polish: Features responsive color-shifting hover animations and dynamic cursor transformations (hand2 pointer feedback) upon mouse entry.
* Smart Grid Architecture: Uses a flexible weight-based layout grid that keeps the interface elements evenly proportional and scales gracefully.
* Robust Safety Checking: Implements real-time code try/catch blocks protecting against typical application-crashing edge cases like division-by-zero errors or malformed syntax entry.
* Zero Dependencies: Built entirely with Python standard libraries (tkinter), requiring no pip install setups or external packages to deploy.

## Built With

* Language: Python 3
* Framework: Tkinter (Standard GUI Library)
